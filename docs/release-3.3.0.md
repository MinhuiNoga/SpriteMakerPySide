# SpriteMaker PySide 3.3.0

## 下載與執行

下載 `SpriteMakerPySide-3.3.0-win64.zip`，完整解壓縮後執行 `SpriteMakerPySide-3.3.0.exe`。請保留同一資料夾內的 `_internal`；不需要另外安裝 Python。

本次正式發布採用本機 `SpriteMakerPySide-3.3.0-preview-fix-win64` 的預覽修正版本，程式及 Windows 檔案版本均為 3.3.0。

## 3.3.0 更新

- 色塊統一支援多個已選影格的作用中圖層；有矩形或套索範圍時只處理範圍內像素，沒有範圍時處理完整作用中圖層。
- 獨立目標顏色選擇器與「使用取樣色」按鈕；重新取樣來源不會覆蓋自訂目標色。
- 修正多選影格時紅色預覽未出現，以及切換目前影格時遺失選取範圍或來源色的問題。
- 目標色與容差變更即時更新預覽；Enter 套用、Esc 取消；整批變更支援一次 Undo/Redo。
- 保留原始 Alpha，忽略完全透明像素；未選影格、其他圖層與範圍外像素保持原樣。

## 自上次 GitHub 3.0.0 發布以來的其他功能

- 腳底對齊：手動／自動錨點、參考影格疊圖、整數位置微調、播放預覽及批次套用。
- 精靈圖匯入：可拖曳的網格、背景設定、自動網格辨識、空白格標示，以及原圖外透明延伸。
- 精靈圖視窗縮放、最大化與 F11 全螢幕，以及可收合設定頁籤。
- 拖入本機圖片即可載入並拆分，與編輯器共用支援的圖片格式。
