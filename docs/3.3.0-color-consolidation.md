# 3.3.0 色塊統一

本次已核准範圍：選取區域內的多 Frame 色塊統一，以及獨立指定目標顏色。

## 邊界與契約

- `MainWindow` 持有影格清單、範圍選取框開關與 Undo/Redo；既有選取事件提供 Canvas 的批次目標。新增目標色／重設按鈕，只有色塊統一工具啟用時顯示。
- `CanvasWidget` 持有來源色、自訂目標色與矩形／套索座標。各 Frame 使用同一座標的區域，裁切至自己的尺寸，不縮放選取範圍。
- `consolidate_similar_colors` 新增尾端選用參數 `target_color=None`：省略時保持原本取樣色目標；比對來源色與容差，改寫目標 RGB，保留 Alpha。回傳統計新增 `targetColor`。
- Canvas 先計算所有結果，再發出一次既有 `editing_started` signal，最後套用全部結果並發出一次既有 `image_changed`。無變更、取消時不寫 Undo。
- `selection_mask_image` 新增選用的 `target_frame` 參數，既有呼叫不變。信號簽名、DB、儲存資料、持久化 Config、檔案格式、外部服務：No change。
- 預覽沒有修改圖層；改變目標、容差或批次目標時重算。切換目前 Frame／作用中圖層／其他工具會沿用既有流程取消來源預覽。自訂目標色保留於目前視窗工具狀態。
