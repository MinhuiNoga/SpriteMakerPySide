# 3.2.0 Sprite Sheet Import

## 實作範圍與資料流

依本次使用者提供的「Sprite Sheet 自動辨識 + 整體 Grid 操作重構」需求實作。

- `sprite_analysis.py`：NumPy 背景 mask、同一套 X/Y 投影與週期評分、分隔距離中位數、部分辨識與 EMPTY 分類。
- `sprite_ops.py`：已知 Grid Rect 的驗證、格子矩形與 row-major 切圖。
- `sprite_grid_preview.py`：來源座標與縮放座標轉換、格線／編號／EMPTY、八個縮放控制點、整體移動、邊界與最小尺寸限制。
- `sprite_import_dialog.py`：參數、辨識結果、背景 mask 快取、勾選與動畫狀態的持有者。

`source_image → detect_spritesheet → 批次更新參數 → refresh_split → split_spritesheet → import_images → replace_with_sprite_frames`

拖曳中的 signal 只同步數值與 overlay；放開後重新切圖、判斷 EMPTY 並建立縮圖。數值修改立即更新合法 overlay，80 ms debounce 後切圖。確認匯入會先完成尚未執行的更新，避免匯入舊尺寸。

## 幾何與狀態契約

- `SpriteSheetLayout` 移除 `outer_margin`，要求 `grid_x/y/width/height`。這是本次明確要求的 API 與跨模組資料結構變更。
- Grid 留在來源範圍內；扣除 separation 後，每格至少一個像素。非整除餘數分配到各格，輸出再補為一致大小；格界不越過 Grid。
- Advanced 保留既有負值重疊語意，仍驗證每格向右／向下推進。
- EMPTY 不刪除格子或變更編號。新 EMPTY 預設不勾選；同一索引的空白狀態未改變時保留手動選擇。Auto Detect 成功時重設預設勾選。
- 無法辨識的軸保留原參數，完全無前景時不覆寫 Grid。無效設定停止切圖並停用匯入，保留來源圖片供修正。
- UI 新增 `gridRectChanged(QRect)`、`gridRectChangeFinished()`，只在匯入視窗內使用。
- MainWindow 匯入／命名／歷史重設契約不變；`app.py` 本次只更新版本字串。
- DB、Save data、持久化 Config、檔案格式、網路與外部服務、交易／重試：No change。
- 原有 `dialog.import_images`、播放、FPS、Loop、選取與 Ctrl+Wheel 保留。

## 驗證與人工檢查重點

基線：修改前 `python -m unittest discover -s tests -q` 為 42 項通過。

新增驗證包括：多種背景、非對稱留白、不同 X/Y separation、噪點與 tolerance、背景空白門檻、失敗／部分結果、角色內部不規則空白、1600→1800 寬度回歸、格子補齊與邊界、八個拖曳控制點／移動／clamp、0.5×／1×／2× 座標、拖曳不重建縮圖、Ctrl+Wheel、Auto Detect 單次 refresh、EMPTY 重新勾選／重新判斷、確認時完成待更新幾何。原有主編輯器整合、命名、Undo/Redo 重設測試保留。

人工檢查重點：使用自己的 sprite sheet 核對角色內距與真實格界。規則吻合分數不是辨識正確率；投影無法唯一還原隱形內距、整列空白或高度重複的角色內部留白。缺乏完整分隔線時可能只辨識一軸或兩軸皆未知。背景顏色只用於分類，不改來源像素。
