# SpriteMaker PySide

[English README](README.md)

SpriteMaker PySide 是一款以 Python + PySide6 製作的本地 Windows 桌面版 sprite 與 frame matting 編輯工具。它用桌面程式取代龐大的單檔 HTML 工作流程，支援繪圖、圖層編輯、影格序列、影片 frame 擷取、Alpha/顏色清理、動畫預覽與 spritesheet 輸出。

## 下載

Windows 使用者可以從 GitHub Releases 下載已打包版本：

- [SpriteMakerPySide-2.0.1-win64.zip](https://github.com/MinhuiNoga/SpriteMakerPySide/releases/latest)

解壓縮後執行：

```text
SpriteMakerPySide-2.0.1.exe
```

Release 版本已包含 Python、PySide6、OpenCV 與必要執行檔，使用者不需要另外安裝 Python。

## 啟動流程

程式啟動後可以選擇兩種流程：

- **匯入影片**：先進入影片 frame 擷取流程。
- **進入編輯模式**：直接進入 sprite 編輯器。

在影片匯入流程中，可以按 **切換到編輯模式** 關閉影片匯入視窗並進入編輯器。

## 支援檔案

- 圖片：`.png`、`.jpg`、`.jpeg`、`.bmp`、`.webp`
- 影片：`.mp4`、`.mov`、`.avi`、`.webm`、`.mkv`

複數圖片匯入時會依檔名自然排序，例如：

```text
frame_1.png
frame_2.png
frame_10.png
```

## 編輯器流程

### 檔案操作

上方 **檔案** 工具列選單包含：

- **匯入** (`Ctrl+O`)：將圖片匯入為新的 frame 序列，會取代目前已有 frame。
- **插入** (`Ctrl+I`)：將圖片插入目前 frame 後方。
- **清空**：清空目前專案。
- **匯入影片**：從編輯模式開啟影片匯入器。
- **儲存單幀** (`Ctrl+S`)：將目前合成 frame 匯出為 PNG。
- **儲存 ZIP**：將所有 frame 匯出成 ZIP。

也可以直接拖放檔案：

- 將一張或多張圖片拖入編輯器，會追加到目前 frame 序列最後面。
- 將影片拖入編輯器，會直接開啟影片匯入流程。
- 將影片拖入「匯入影片」視窗本身，也會直接載入該影片。

### 影格序列

下方影格視窗包含：

- 上一幀
- 下一幀
- 複製幀
- 刪除幀
- frame 縮圖序列

可以在影格序列中拖曳縮圖重新排序，排序操作會進入 undo 歷史。

### 圖層

圖層視窗支援：

- 新增圖層
- 複製圖層
- 刪除圖層
- 圖層上移/下移
- 顯示/隱藏圖層
- 選擇作用中圖層
- 調整作用中圖層透明度
- 如果圖層視窗被關閉，可用 **圖層視窗** 按鈕再次開啟

繪圖、填色、擦除、刪除選取內容、選取剪貼等操作會套用在作用中圖層；單幀去色和全域去色則會依工具邏輯處理多圖層或多 frame。

### 畫布與視圖

- `Ctrl + 滾輪`：縮放主畫布。
- `Ctrl+0`：畫布縮放回 100%。
- 使用捲動條編輯畫面外的區域。
- 畫面中的黑框代表目前全域輸出畫布尺寸。
- 修改 **輸出W**、**H** 可改變全域輸出尺寸。
- **目前尺寸** 會將輸出尺寸設為目前 frame 尺寸。
- **中心線** 可顯示水平/垂直中心線。
- **透明格** 可切換透明棋盤格背景。
- **背景** 可選擇純色預覽背景。

## 繪圖工具

### 顏色與筆刷設定

- **顏色**：選擇畫筆、填色、去色目標色，支援 Alpha 透明度。
- **透明**：將目前顏色設為完全透明。
- **筆刷**：控制畫筆與橡皮擦大小。
- **容差**：控制填色、魔術棒、單幀去色與全域去色的顏色容差。
- `Alt + 點擊畫布`：取樣目前可見像素顏色並更新工具列顏色。

### 工具列表

- **選取** (`V`)：矩形選取。
- **繩索** (`L`)：自由形狀選取。
- **畫筆** (`B`)：使用目前顏色與筆刷大小繪圖。
- **橡皮擦** (`E`)：使用目前筆刷大小擦除。
- **填色** (`G`)：依目前顏色與容差填滿作用中圖層的連通區域。
- **魔術棒** (`W`)：在作用中圖層擦除連通色域。
- **單幀去色** (`Shift+W`)：在目前 frame 的所有圖層中擦除符合目標色的像素。
- **全域去色** (`U`)：在所有 frame、所有圖層中擦除符合目標色的像素。

去色工具邏輯：

- 魔術棒點擊位置只決定起始連通區域。
- 目標顏色使用工具列目前顏色 + 容差。
- 單幀去色和全域去色會處理所有符合像素，不限定連通區域。

## 選取與剪貼操作

選取內容支援：

- 複製 (`Ctrl+C`)
- 剪下 (`Ctrl+X`)
- 貼上 (`Ctrl+V`)
- 刪除選取像素 (`Delete`)
- 拖曳選取內容
- 用方向鍵移動選取框或浮動貼上內容
- 按住 `Shift` 加方向鍵可一次移動 10px
- 用畫面上的黃色控制點自由旋轉浮動內容
- 用角落控制點自由縮放浮動內容
- 縮放時按住 `Shift` 可等比例縮放
- `R` 將浮動內容旋轉 90 度
- `H` 水平翻轉浮動內容
- `Shift+H` 垂直翻轉浮動內容

貼上到不同 frame 時，會貼到複製時的同座標位置。

## 影片匯入流程

影片匯入器支援選擇影片或直接拖入影片。

### 影片預覽頁

- 選取影片後會循環播放目前開始/結束時間範圍。
- 使用綠色與紅色圓點設定開始與結束時間。
- 使用黃色播放點調整目前預覽位置。
- 拖曳時間點時會暫停播放，放開後恢復，降低卡死機率。
- 可用 **播放/暫停** 控制預覽。
- 在預覽畫面上使用 `Ctrl + 滾輪` 可縮放。
- 目標 FPS 預設為 `12 FPS`。
- 按 **擷取 frame** 後，會依目前時間範圍與目標 FPS 擷取影格。

### 選擇保留 frame 頁

擷取後會進入乾淨的 frame 篩選頁：

- 左上：已勾選 frame 的動畫預覽。
- 右上：單張 frame 預覽。
- 下方：擷取出的 frame 縮圖序列。
- 可拖曳分隔線調整各區塊大小。
- 在預覽或 frame 序列使用 `Ctrl + 滾輪` 可縮放。
- 勾選/取消勾選 frame 來決定要保留哪些。
- 長按 frame 後拖曳可進入範圍選取模式，快速加入或取消多個 frame。
- 動畫預覽支援播放/暫停、自訂 FPS、進度條拖曳與循環播放。
- **全選**、**全不選**、**反選** 可快速管理選取狀態。
- **儲存 PNG** 會建立 `matted_frames.zip`。
- **匯入編輯器** 會將勾選 frame 匯入主編輯器。

儲存的 frame 會放在 `matted_frames.zip` 中，命名格式：

```text
matte_00001.png
matte_00002.png
matte_00003.png
...
```

## 編輯器動畫預覽

從輸出工具列按 **動畫預覽** 開啟。

功能包含：

- 自訂播放 FPS。
- 設定循環播放的開始/結束 frame。
- 右側顯示所有匯入 frame 的縮圖。
- 點擊縮圖可立即預覽該 frame。
- **設為開始**、**設為結束** 可快速用縮圖設定循環範圍。
- 播放時右側縮圖會跟著目前 frame 更新。
- `Ctrl + 滾輪` 可縮放動畫預覽。

## Spritesheet 預覽與輸出

從輸出工具列按 **Spritesheet** 開啟。

可調整：

- 欄位數
- 如果有設定輸出尺寸，單格會使用該輸出尺寸
- 扣除接觸透明背景的邊緣 pixel
- 啟用外框並設定外框粗細
- 選擇外框顏色
- 預覽縮放滑桿與 `Ctrl + 滾輪` 縮放
- 將 spritesheet 儲存為 PNG

## 從原始碼執行

需求：

- Python 3.9 或更新版本
- PySide6
- NumPy
- Pillow
- OpenCV
- PyInstaller，只有打包 Windows 版本時需要

安裝依賴：

```powershell
py -m pip install -r requirements.txt
```

執行：

```powershell
py -m sprite_maker
```

或：

```powershell
.\start.ps1
```

## 打包 Windows App

先安裝依賴，然後執行：

```powershell
.\build_exe.ps1
```

建置輸出已在 `.gitignore` 中排除，不會提交到 GitHub。
