# SpriteMaker PySide

[English README](README.md)

SpriteMaker PySide 是一款以 Python + PySide6 製作的本地 Windows 桌面版 sprite 與 frame matting 編輯工具。它用桌面程式取代龐大的單檔 HTML 工作流程，支援繪圖、圖層編輯、影格序列、影片／GIF frame 擷取、Alpha/顏色清理、指定色邊緣融色修復、動畫預覽與 spritesheet 輸出。

## 下載

Windows 使用者可以從 GitHub Releases 下載已打包版本：

- [SpriteMakerPySide-2.5.0-win64.zip](https://github.com/MinhuiNoga/SpriteMakerPySide/releases/latest)

解壓縮後執行：

```text
SpriteMakerPySide-2.5.0.exe
```

Release 版本已包含 Python、PySide6、OpenCV 與必要執行檔，使用者不需要另外安裝 Python。

## 2.5.0 更新重點

- 在啟動選擇、檔案選擇器與拖放流程中，為 **匯入影片 / GIF** 模式加入動態 GIF 支援。
- GIF 預覽會依照原始檔每個 frame 的個別延遲播放，保留透明背景，並只在使用者指定的開始／結束區間內循環。
- 依不等長的 frame 延遲建立累積時間軸，拖曳播放進度、開始點與結束點時會顯示正確的來源 frame。
- 可依目標 FPS 重新取樣選定的 GIF 時間範圍，再進入既有的 frame 勾選頁面。
- GIF 固定使用精確時間對應，不套用影片的清晰幀替換，避免動畫姿勢或刻意停留的 frame 被換掉。
- 將動態 GIF 拖入編輯器時會開啟動畫匯入流程；單幀 GIF 則維持一般圖片匯入行為。

## 2.4.3 更新重點

- 將原本的像素融色畫筆完整替換成正規的 **模糊筆刷**，改為柔化既有圖片細節，不再把目前前景色畫進筆畫邊緣。
- 新增可調整的模糊強度、高斯半徑、筆刷硬度與保持 Alpha 選項。
- 使用 Alpha-aware 預乘取樣，透明像素中不可見的 RGB 不會污染角色的可見邊緣。
- 每次按下滑鼠固定使用一份來源快照，並以本次筆畫的最大覆蓋率計算；同一筆重複經過相同位置不會遞迴模糊已經模糊的結果。
- 矩形與繩索選取會限制實際修改像素；工具仍只處理目前 frame 的作用中圖層，且每筆只建立一筆 undo/redo 紀錄。

## 2.4.2 更新重點

- 將編輯模式的匯入與拖放功能由 PNG／JPEG 擴充到普遍使用的其他圖片格式。
- 支援 JPEG 延伸格式（`JPE`、`JFIF`、`JIF`、`JFI`）、`BMP/DIB`、`GIF`、`WebP`、`TIFF`、`TGA`、`ICO/ICNS`、`PBM/PGM/PPM`、`XBM/XPM` 與 `SVG/SVGZ`。
- 使用 Qt 圖片解碼與自動方向校正，並加入 Pillow 後備載入，提高不同圖片來源的相容性。
- 透過一般圖片指令匯入動態或多頁圖片時，仍使用第一個 frame／頁面；若要保留並擷取完整 GIF 時間軸，請使用 **匯入影片 / GIF**。
- 複數圖片維持依檔名自然排序，例如 `frame_2` 會排在 `frame_10` 前面。

## 2.4.1 更新重點

- 將像素壓縮化原本固定的 `1/2`、`1/4`、`1/8` 快速比例按鈕改為連續的 **輸出比例** 滑條。
- 滑條範圍為 `1%` 到 `100%`，每次可細調 `0.5%`，預設為 `25%`。
- 滑條旁會顯示目前百分比，並在 `1/2`、`1/4`、`1/8` 等常用比例顯示熟悉的分數。
- 拖曳時會立即更新邏輯寬高，但只在放開滑條後重新計算圖片預覽，減少不必要的連續運算。
- 保留手動邏輯寬高輸入；解除鎖定比例後，單一比例滑條會停用，並顯示各自的寬／高百分比。

## 2.4.0 更新重點

- 新增 **色塊統一**，可將 diffusion 生圖產生的近似雜色收斂成一個取樣標準色。
- 在目前圖層點擊可見像素取得標準色，並沿用工具列既有容差判斷接近的 RGB 顏色。
- 預覽會掃描矩形／繩索選取內所有符合像素，即使彼此不相連也會命中；沒有選取時則掃描完整作用中圖層。
- 紅色遮罩會預覽所有命中像素，狀態列同時顯示取樣色、容差、命中數與實際變更數。
- 按 `Enter` 套用預覽，按 `Esc` 取消；重新點擊其他像素可更換標準色。
- 只統一 RGB，每個像素原有 Alpha 保持不變，並忽略 Alpha 為 0 的完全透明像素。
- 只修改目前 frame 的作用中圖層，套用時建立一筆 undo/redo 紀錄。

## 2.3.4 更新重點

- 在編輯模式工具列新增 **像素壓縮化**。
- 像素壓縮化只處理目前 frame 的作用中圖層，其他圖層與其他 frame 不會改變。
- 已有矩形或繩索選取時，只處理選取內的像素；沒有選取時，處理整個作用中圖層。
- 選取區域會先縮小至使用者指定的邏輯解析度，再以最近鄰放大回原尺寸，產生可控制的像素化效果。
- 提供 Alpha 加權區域取樣、區域主色與最近鄰三種模式。Alpha 感知取樣會避免透明像素中不可見的 RGB 污染可見顏色。
- 提供鎖定比例、`1/2`、`1/4`、`1/8` 快速比例，以及原圖／結果並排預覽。
- 套用結果只建立一筆 undo，且不會改變 frame、圖層、畫布或選取區域的尺寸。

## 2.3.3 更新重點

- 範圍選取框的同步移動、縮放、旋轉、翻轉與刪除，現在只作用於 frame 序列中目前選取的 frame。
- 單選一個縮圖時只修改該 frame；以 `Shift` 選取連續區間或以 `Ctrl` 選取不連續縮圖時，只修改實際選取的 frame。

## 2.3.2 更新重點

- Spritesheet 預設改為扣除邊緣 `1 px`、啟用扣邊抗鋸齒，並使用 `2.00 px` 輪廓平滑。
- 外框維持預設關閉，但預先將外框寬度設為 `1 px`，啟用後可直接使用。

## 2.3.1 更新重點

- 將高記憶體用量的超取樣扣邊改為 OpenCV 原尺寸輪廓重繪，以抗鋸齒填滿輪廓處理新邊界。
- 可關閉「扣邊抗鋸齒」，恢復適合 pixel art 的四方向硬式逐層扣除。
- 新增可調整的 `0–2 px` 輪廓平滑，以最大偏差輪廓擬合拉直淺斜線階梯；預設 `1 px`，明顯尖角仍會保留。
- 外框改沿扣邊後影像的 `50% Alpha` 輪廓生成，避免極淡抗鋸齒像素被放大成黑色階梯。
- 外框改為合成在低 Alpha 邊緣像素下方，消除抗鋸齒扣邊與外框之間看似透明的間隙。
- 移除獨立的外框平滑控制與 Gaussian 外框處理。
- 進入編輯畫面時只預設開啟 frame 序列；圖層與邊緣融色修復面板維持關閉，使用時再由工具列開啟。
- Spritesheet 預覽與儲存 PNG 使用相同的輪廓抗鋸齒結果。
- Spritesheet 非 1:1 預覽縮放改用高品質平滑取樣，不再以快速近鄰式縮放放大鋸齒；儲存 PNG 的原始像素不受影響。

## 2.3.0 更新重點

- 將逐時間點反覆跳轉改為只定位一次後連續解碼，維持來源 frame 順序並取得更可靠的實際時間。
- 新增 **精確時間**、**平衡（推薦）** 與 **清晰優先** 三種擷取策略，預設使用平衡模式。
- 平衡與清晰優先模式會依 Laplacian 清晰度、目標時間距離、來源 frame 間隔及場景色彩分布，從附近候選中挑選結果。
- 候選 frame 使用小型循環緩衝區，選定後即釋放舊資料，不會把整段未壓縮影片全部留在記憶體。
- 每個擷取結果會記錄目標時間、實際來源時間、時間偏移、來源編號、清晰度與清晰度百分位。
- 低清晰度 frame 不會被自動刪除，而是在篩選頁顯示紅色標記、詳細提示與數量統計。
- 程式不會自動銳化或生成不存在的細節。

- 將原本的 `3×3` 方形腐蝕核心改為四方向腐蝕，避免 `45°` 斜邊、髮絲與傾斜衣物輪廓一次被吃掉兩個階梯像素。
- 每增加一個扣除值就只再移除一層，預覽與實際輸出共用相同的修正流程。

## 2.2.8 更新重點

- 修正選取內容旋轉時的抖動：整次拖曳固定使用按下旋轉控制點當下的中心、起始向量與起始角度。
- 旋轉角度直接由凍結的起始向量計算，不會讓中途預覽的角度或小數誤差回授到下一次滑鼠移動。
- 選取內容旋轉超出現有圖片邊界、造成工作區自動擴張時，會補償座標位移，避免角度突然跳動。
- 平滑預覽與最終寫回都持續由原始浮動選取內容取樣，不會反覆旋轉已經插值過的影像。

- 修正選取內容縮放時的抖動與撕裂感：整段拖曳固定使用按下控制點當下的 transform 計算，不再將每次更新後的 scale 回授到下一次滑鼠移動。
- `Shift` 等比例縮放改用單一穩定的徑向比例同步控制兩軸。
- 新增 **變形品質**：預設 **平滑** 會以插值處理縮放／旋轉；**像素銳利** 則保留 nearest-neighbor 像素邊緣。畫面預覽與最終寫回一定使用相同品質。

- 可分別調整融色強度、邊緣寬度、取樣半徑、取樣來源與透明邊緣行為。
- 取樣來源可選目前圖層或所有可見圖層；透明像素預設不參與，也可開啟 **透明淡邊** 產生半透明筆畫邊緣。

- 融色使用局部 NumPy／OpenCV 運算及穩定的落筆前快照，避免同一筆反覆取樣自身而變髒，並維持大筆刷繪製效能。
- 每筆結束後，狀態列會顯示實際因融色而改變的像素數；完全找不到鄰色時也會直接提示。

## 啟動流程

程式啟動後可以選擇兩種流程：

- **匯入影片 / GIF**：先進入影片或動態 GIF 的 frame 擷取流程。
- **進入編輯模式**：直接進入 sprite 編輯器。

在影片／GIF 匯入流程中，可以按 **切換到編輯模式** 關閉匯入視窗並進入初始化的編輯器。程式會先警告擷取 frame 不會被帶入；要保留勾選 frame 時請使用 **匯入編輯器**。

## 支援檔案

- 圖片：PNG、JPEG/JPG/JPE/JFIF/JIF/JFI、BMP/DIB、GIF、WebP、TIFF、TGA、ICO/ICNS、PBM/PGM/PPM、XBM/XPM、SVG/SVGZ
- 動畫匯入器：`.mp4`、`.mov`、`.avi`、`.webm`、`.mkv`、動態 `.gif`

## 編輯器流程

### 檔案操作

上方 **檔案** 工具列選單包含：

- **匯入** (`Ctrl+O`)：將圖片匯入為新的 frame 序列，會取代目前已有 frame。
- **插入** (`Ctrl+I`)：將圖片插入目前 frame 後方。
- **清空**：清空目前專案。
- **匯入影片 / GIF**：從編輯模式切換到動畫匯入器。程式會先警告目前編輯專案與歷史將被初始化，只有確認後才會切換。
- **儲存單幀** (`Ctrl+S`)：將目前合成 frame 匯出為 PNG。
- **儲存 ZIP**：依目前排列順序將所有 frame 匯出成 ZIP，並重新命名為 `video_frame_0001.png`、`video_frame_0002.png`，依此類推。

儲存單幀、frame ZIP、spritesheet 與影片擷取 ZIP 的對話視窗，會預設開啟最近匯入圖片或影片所在的資料夾；尚未匯入檔案時則使用使用者主目錄。

也可以直接拖放檔案：

- 將一張或多張圖片拖入編輯器，會追加到目前 frame 序列最後面。
- 將影片或動態 GIF 拖入編輯器，會直接開啟動畫匯入流程；單幀 GIF 維持一般圖片匯入。
- 將影片或 GIF 拖入 **匯入影片 / GIF** 視窗本身，也會直接載入。

可匯入的圖片格式包含 PNG、JPEG/JPG/JPE/JFIF/JIF/JFI、BMP/DIB、GIF、WebP、TIFF、TGA、ICO/ICNS、PBM/PGM/PPM、XBM/XPM 與 SVG/SVGZ。透過一般圖片指令匯入動態 GIF 時只使用第一個 frame；完整時間軸請使用 **匯入影片 / GIF**。

### 影格序列

下方影格視窗包含：

- 上一幀
- 下一幀
- 複製幀
- 刪除幀
- frame 縮圖序列

可以在影格序列中拖曳縮圖重新排序，排序操作會進入 undo 歷史。

多 frame 操作方式：

- 先點一個 frame，再按住 `Shift` 點另一個 frame，即可選取包含兩端的連續區間。
- 影格列有焦點時按 `Delete`，會一次刪除所有已選 frame；一次 undo 可還原完整範圍。
- 拖曳任一已選縮圖，可將整段選取區間移動到新位置，區間內順序不變。
- 建立矩形或繩索選取前開啟 **範圍選取框**，同步操作只會套用到 frame 序列目前選取的縮圖。
- 移動、縮放、旋轉、翻轉或刪除選取內容，會將相同變形套用到每個目標 frame；一次復原即可還原完整同步操作。
- 選取區間後開啟動畫預覽，該區間會成為預設播放範圍。

### 圖層

圖層視窗支援：

- 新增圖層
- 複製圖層
- 刪除圖層
- 圖層上移/下移
- 顯示/隱藏圖層
- 選擇作用中圖層
- 調整作用中圖層透明度
- 如果圖層視窗被關閉，可用 **圖層視窗** 按鈕再次開啟

繪圖、填色、擦除、刪除選取內容、選取剪貼等操作會套用在作用中圖層；單幀去色和全域去色則會依工具邏輯處理多圖層或多 frame。

### 畫布與視圖

- `Ctrl + 滾輪`：縮放主畫布。
- `Ctrl+0`：畫布縮放回 100%。
- 使用捲動條編輯畫面外的區域。
- 畫面中的黑框只提示目前全域輸出裁切範圍，不會限制任何編輯操作。
- 畫筆或選取內容跨過原始圖片邊界時，透明工作區會自動擴張。
- 黑框外像素仍會保留在 frame、圖層及 undo/redo 中；只有將 **輸出W／H** 放大到涵蓋它們時才會匯出。
- 修改 **輸出W**、**H** 可改變全域輸出尺寸。
- **目前尺寸** 會將輸出尺寸設為目前 frame 尺寸。
- **中心線** 可顯示水平/垂直中心線。
- **透明格** 可切換透明棋盤格背景。
- **背景** 可選擇純色預覽背景。

## 繪圖工具

### 顏色與筆刷設定

- **顏色**：選擇畫筆、填色、去色目標色，支援 Alpha 透明度。
- **透明**：將目前顏色設為完全透明。
- **筆刷**：控制畫筆與橡皮擦大小。
- **容差**：控制填色、魔術棒、單幀去色與全域去色的顏色容差。
- `Alt + 點擊畫布`：取樣目前可見像素顏色並更新工具列顏色。

### 模糊筆刷

開啟 **模糊筆刷** 後，筆刷會柔化游標經過位置的既有像素，不會畫入目前工具列的前景色：

- **強度** (`0-100%`)：原圖與模糊結果的混合比例。
- **半徑** (`1-32 px`)：高斯取樣半徑；數值越大，柔化範圍越廣。
- **硬度** (`0-100%`)：筆刷中心完整作用區的大小；數值越低，邊緣漸淡範圍越寬。
- **保持 Alpha**：維持每個像素原有透明度，只修改 RGB；預設開啟。

預設值為強度 50%、半徑 4 px、硬度 50%，並開啟保持 Alpha。Alpha-aware 預乘取樣會避免透明像素中的不可見顏色滲入角色邊緣。每次按下滑鼠時固定建立一份作用中圖層快照，因此同一筆重複經過相同位置不會遞迴模糊。已有矩形或繩索選取時只修改選取內像素；沒有選取時則依圓形筆刷經過範圍處理。每筆結束建立一筆 undo/redo 紀錄，狀態列會顯示實際改變的像素數。橡皮擦、填色、其他圖層、其他 frame 與指定色邊緣融色修復都不受影響。

### 像素壓縮化

使用編輯模式工具列的 **像素壓縮化**，可以在維持原始圖片尺寸的情況下產生低解析度像素風格：

- 只處理目前 frame 的作用中圖層。
- 有矩形或繩索選取時，只改變選取內的像素；沒有選取時，處理整個作用中圖層。
- 可自行設定邏輯輸出寬度與高度，或使用 `1%` 到 `100%` 的輸出比例滑條；滑條支援 `0.5%` 細調，並會在 `50%`、`25%`、`12.5%` 顯示常用分數。
- 拖曳滑條時會立即更新目標尺寸，放開後才重新計算預覽；解除鎖定比例後可分別輸入自訂寬度與高度。
- **Alpha 加權區域取樣**會穩定平均縮小後的顏色，並忽略透明像素中不可見 RGB 對可見色的污染。
- **區域主色**會保留每個邏輯像素區塊內最主要的顏色。
- **最近鄰**會直接取得硬邊像素。
- 壓縮結果會以最近鄰放大回原處理範圍；選取外像素、其他圖層與其他 frame 都維持不變。
- 套用前可並排比較原圖與結果；套用後會建立一筆可復原／重做的歷史紀錄。

### 色塊統一

使用 **色塊統一** 可以清除 diffusion 生圖產生的大量近似雜色：

1. 可先用矩形或繩索圈出要整理的角色部位。
2. 切換到 **色塊統一**，再點擊應該保留的正確顏色。
3. 視需要調整工具列既有容差，紅色命中遮罩會即時更新。
4. 按 `Enter` 將所有命中 RGB 統一成取樣 RGB，或按 `Esc` 取消。

色塊統一和油漆桶不同，不要求命中像素互相連通。它會掃描完整選取範圍；沒有選取時則掃描完整作用中圖層。每個像素都直接和最初取樣色比較，因此容差不會沿著漸層逐步擴散。完全透明像素會被忽略；可見與半透明像素會保留各自原本的 Alpha。

### 工具列表

- **選取** (`V`)：矩形選取。
- **繩索** (`L`)：自由形狀選取。
- **畫筆** (`B`)：使用目前顏色與筆刷大小繪圖。
- **橡皮擦** (`E`)：使用目前筆刷大小擦除。
- **填色** (`G`)：依目前顏色與容差填滿作用中圖層的連通區域；矩形選取存在時，填色只會在選取範圍內擴散。繩索選取存在時，點擊選取內會直接以目前顏色填滿整個繩索範圍。
- **色塊統一**：點擊一個標準色，將目前選取或作用中圖層內所有近似 RGB 統一成該色，不限定連通區域；`Enter` 套用，`Esc` 取消預覽。
- **魔術棒** (`W`)：在作用中圖層擦除連通色域。
- **單幀去色** (`Shift+W`)：在目前 frame 的所有圖層中擦除符合目標色的像素。
- **全域去色** (`U`)：在所有 frame、所有圖層中擦除符合目標色的像素。

去色工具邏輯：

- 魔術棒點擊位置只決定起始連通區域。
- 目標顏色使用工具列目前顏色 + 容差。
- 單幀去色和全域去色會處理所有符合像素，不限定連通區域。

### 指定色邊緣融色修復

右側 **邊緣融色修復** 面板可修復 alpha 邊緣附近的指定顏色殘邊，不會把全圖相同顏色直接替換掉。面板被關閉或藏起來時，可用上方工具列的 **融色面板** 按鈕重新叫出。

此功能直接沿用既有狀態：

- 殘邊污染色：工具列目前選取顏色。
- 顏色容差：工具列既有容差數值。

可調整：

- **修復強度**：`0` 到 `1`，預設 `0.8`。
- **邊緣寬度**：處理 alpha 邊緣 `1` 到 `10 px` 範圍，預設 `3 px`。
- **Alpha 收縮**：可選擇小幅吃掉 alpha 邊緣 `0` 到 `3 px`，預設 `0`。
- **邊緣柔化**：可選擇柔化補色權重 `0` 到 `3 px`，預設 `0`。
- **啟用邊緣補色**：替透明邊緣 padding 寫入內側乾淨 RGB，但保持原本 alpha。
- **套用範圍**：目前選取圖層、目前幀所有圖層、所有幀所有圖層；矩形或繩索選取存在時，融色只會改變選取範圍內的像素，鄰近乾淨顏色取樣仍可參考選取外側，確保補色自然。

適合修復綠幕、紅幕、藍幕、AI 生成殘邊、去背殘色與透明 PNG 縮放時露出的污染色。它只會處理靠近 alpha 邊緣且接近目前工具列顏色的像素，角色內部同色裝飾不會被全圖誤改。污染邊緣像素會使用附近角色內側乾淨顏色補回，alpha 預設保持原本數值，只有 **Alpha 收縮** 大於 `0` 時才會收縮 alpha。

Debug 控制：

- **顯示 Debug Overlay**：在畫布上疊加目前選擇的診斷遮罩。
- **Overlay 類型**：可選 `innerEdgeBand`、`outerPaddingBand`、`semiTransparentBand`、`contaminatedMask`、`lookupFallback`、`actualChangedPixels` 或 `allDebugMasks`。
- **污染像素測試塗色**：將被判定為污染的像素直接塗成亮紅色，alpha 保持原值。
- **只執行偵測，不套用修復**：只建立遮罩、統計與 overlay，不寫回圖片。
- **輸出本次修復統計到 console**：重新印出最近一次統計。

每次執行都會在 console 輸出統計，包含 mask 數量、污染像素數量、乾淨補色尋找成功/失敗數、RGB/alpha 實際改變數、平均 RGB 變化量、平均/最大修復權重，以及 before/after RGB/alpha sum。

## 選取與剪貼操作

選取內容支援：

- 複製 (`Ctrl+C`)
- 剪下 (`Ctrl+X`)
- 貼上 (`Ctrl+V`)
- 刪除選取像素 (`Delete`)
- 拖曳選取內容
- 用方向鍵移動選取框或浮動貼上內容
- 按住 `Shift` 加方向鍵可一次移動 10px
- 用畫面上的黃色控制點自由旋轉浮動內容
- 用角落控制點自由縮放浮動內容
- 縮放時按住 `Shift` 可等比例縮放
- 使用 **平滑** 變形品質降低縮放／旋轉的撕裂感，或切換 **像素銳利** 保留 nearest-neighbor 像素邊緣
- `R` 將浮動內容旋轉 90 度
- `H` 水平翻轉浮動內容
- `Shift+H` 垂直翻轉浮動內容
- 按 `Esc` 或點擊選取框外的像素，可完成目前變形並退出選取

貼上到不同 frame 時，會貼到複製時的同座標位置。

## 影片 / GIF 匯入流程

動畫匯入器支援選擇或直接拖入影片與 GIF。

### 影片 / GIF 預覽頁

- 選取影片或 GIF 後會循環播放目前開始／結束時間範圍；GIF 會保留透明背景與每個 frame 的個別延遲。
- 使用綠色與紅色圓點設定開始與結束時間。
- 使用黃色播放點調整目前預覽位置。
- 拖曳時間點時會暫停播放，放開後恢復，降低卡死機率。
- 可用 **播放/暫停** 控制預覽。
- 在預覽畫面上使用 `Ctrl + 滾輪` 可縮放。
- 目標 FPS 預設為 `12 FPS`。
- 影片可選擇 **精確時間**、**平衡（推薦）** 或 **清晰優先**；GIF 固定使用精確時間對應，以保留原本姿勢與停留 frame。
- 按 **擷取 frame** 後，會連續解碼選定範圍並依目標 FPS 選擇影格。

### 選擇保留 frame 頁

擷取後會進入乾淨的 frame 篩選頁：

- 左上：已勾選 frame 的動畫預覽。
- 右上：單張 frame 預覽。
- 下方：擷取出的 frame 縮圖序列，取消勾選的 frame 會顯示半透明灰色遮罩。
- 低清晰度 frame 會顯示紅色標記，但仍保持勾選並可自由保留或取消。
- 將滑鼠停在縮圖上，可查看目標時間、來源時間、偏移、來源 frame 編號與清晰度。
- 可拖曳分隔線調整各區塊大小。
- 在預覽或 frame 序列使用 `Ctrl + 滾輪` 可縮放。
- 勾選/取消勾選 frame 來決定要保留哪些。
- 長按 frame 後拖曳可進入範圍選取模式，快速加入或取消多個 frame。
- 動畫預覽支援播放/暫停、自訂 FPS、進度條拖曳與循環播放。
- **全選**、**全不選**、**反選** 可快速管理選取狀態。
- **儲存 PNG** 會建立 `matted_frames.zip`。
- **匯入編輯器** 會將勾選 frame 匯入主編輯器。

儲存的 frame 會放在 `matted_frames.zip` 中，命名格式：

```text
matte_00001.png
matte_00002.png
matte_00003.png
...
```

## 編輯器動畫預覽

從輸出工具列按 **動畫預覽** 開啟。

功能包含：

- 自訂播放 FPS。

- 右側顯示所有匯入 frame 的縮圖。
- 點擊縮圖可立即預覽該 frame。
- **設為開始**、**設為結束** 可快速用縮圖設定循環範圍。
- 播放時右側縮圖會跟著目前 frame 更新。
- `Ctrl + 滾輪` 可縮放動畫預覽。

## 從原始碼執行

需求：

- Python 3.9 或更新版本
- PySide6
- NumPy
- Pillow
- OpenCV
- PyInstaller，只有打包 Windows 版本時需要

安裝依賴：

```powershell
py -m pip install -r requirements.txt
```

執行：

```powershell
py -m sprite_maker
```

或：

```powershell
.\start.ps1
```

## 打包 Windows App

先安裝依賴，然後執行：

```powershell
.\build_exe.ps1
```

建置輸出已在 `.gitignore` 中排除，不會提交到 GitHub。
